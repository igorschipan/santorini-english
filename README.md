# Santorini English

English practice app for the manager of Santorini Greek Restaurant (Bali): lessons with guests, staff, suppliers and the owner, the real menu, and role-play prompts for ChatGPT voice mode.

Open: https://igorschipan.github.io/santorini-english/

- `index.html` - the app (built from `src/`)
- `perenos.html` - moves progress from the old single-file version
- `assets/` - images: restaurant photos and menu dishes, illustrations generated with Codex, sketches from Gemini
